# 历史源码与基线归档

这个目录用于保留整理过程中发现的旧版源码、测试基线和来源说明。它的目的是让代码可追溯，不是让所有版本同时参与编译。

## 目录说明

- `stm32_variants/`：最终同步 STM32 主线前，仓库中存在内容差异的文件备份。
- `ros_history/`：`sunyan.zip` 中 4 个历史 catkin 工作空间的 `src` 树。
- `ros_baseline/2025-04-03/`：2025-04-03 测试基线的 ROS 源码快照及原始小型备份包。
- `source_notes/`：原始工程的来源说明。

## 使用规则

1. 日常阅读和编译以仓库根目录的 STM32 工程及 `ros1_ws/src` 为准。
2. `ros_history/` 中多个工作空间包含同名 ROS 包，不能全部拷贝到同一 `src` 目录后直接编译。
3. 需要回溯历史行为时，从对应归档复制到独立工作空间中验证。
4. `build/`、`devel/`、Keil 中间文件等可重建产物不作为源码保存。

本轮整理遵循“先备份、再同步”，没有删除用户原始代码。
